# Run the revisit gate automatically at intake

ADR 0002 and D07 send a context package to hosted inference only after the user reviews it and presses send, and the first spec states that intake starts no background model generation. The revisit gate is a deliberate, narrow exception. After a check admits new evidence, Companion sends each revisit candidate to the model without a per-send review and raises a notice only when the gate answers that the revisit condition is met.

The reason is the purpose of the feature. A gate that waits for the user to press "check" asks the user to remember to look, which is the prospective-memory failure the decision ledger is meant to cover. PM-Bench finds that monitoring which depends on an agent choosing to look is the weakest slice it measures (Liu & Gabriel 2026, §4.3), and MemoProAgent defines proactive assistance as deciding with no query from the user (Zeng et al. 2026, §3.1).

The exception is bounded. Automatic checks are off until explicitly enabled. Each package has a fixed shape (the condition, the decision's choice and reasons, the matched passages, earlier notice outcomes) drawn only from the Discovery Corpus, with rejected and removed sources excluded, under the existing 32,000-character limit. Requests use the same fresh isolated threads as chat. The reply can only raise a notice; it cannot write to the ledger. Requests are capped per check, failures are never replayed, and every package is stored for inspection after the fact. Chat, comparison and brief generation keep the review-before-send rule unchanged.

This accepts three costs: content leaves the PC without a per-send review, model usage happens unattended, and captured text reaches the model without a human reading it first. See D44–D47 in [the draft spec](../decision-revisit-spec.md). The user chose this on 2026-11-20 over a reviewed, user-sent gate. The gate is implemented behind both readiness checks and stays closed in production until isolation of automatic requests from the scheduled worker is verified on the target machine.
